# hack-7c95a80f-paraplan

Хакатонный проект ParaPlan: симулятор «Аким на 5 часов» для оценки сценариев распределения городского бюджета.

## Запуск

1. Откройте папку репозитория в Visual Studio Code.
2. Запустите сайт кнопкой **Go Live** в правом нижнем углу (расширение Live Server).
3. Выберите пять мероприятий. Для районных инициатив укажите район.
4. Нажмите **Загрузить пример из кейса**, чтобы увидеть готовый сценарий.

Для первой версии не нужны npm-пакеты, API-ключи, персональные данные или отдельный сервер приложения.

## Файлы

- index.html — страница симулятора.
- style.css — адаптивное оформление.
- src/data.js — районы, показатели, меры, их стоимость, лаги, эффекты, синергии и несовместимости.
- src/model.js — проверка правил, влияние мер и формула Astana Quality of Life Score.
- src/app.js — интерактивный интерфейс, бюджет, районные карточки и разбор результата.

## Модель

Все показатели лежат в диапазоне 0–100. Эффекты мер умножаются на долю реализации (8 − лаг) / 8. Городские меры действуют на все районы, районные — на выбранный район. После применения эффектов и синергий показатели ограничиваются шкалой 0–100.

AQOL Score = 0.7 × средний балл районов с учётом населения + 0.3 × балл слабейшего района − число показателей ниже 40.

Сценарий допустим, если выбрано ровно пять разных мер, бюджет не выше 100, на одно направление приходится не больше двух мер, выбраны районы для районных мер, не выбраны районы для городских мер и не нарушены несовместимости. Недопустимый сценарий не получает итоговый балл.

Объяснение результата формируется детерминированно из вычисленных данных: показывает изменения районов, ведущие направления, критические значения, затраты и сработавшие синергии. Модель сама рассчитывает все числа; текст не добавляет вымышленных показателей.
